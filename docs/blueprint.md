# **App Name**: Wardley Canvas

## Core Features:

- Interactive Map Editor: An intuitive drag-and-drop interface to create, arrange, and connect components on a Wardley map canvas, allowing users to define component stages (Genesis, Custom-built, Product, Commodity).
- Wardley Concepts Guide: A dedicated section providing comprehensive explanations of Wardley mapping principles, concepts, and evolutionary stages to educate new and experienced users.
- Map Export Functionality: Enable users to export their created Wardley maps in high-quality PDF and PNG formats for easy sharing and documentation.
- Pre-built Map Templates: A gallery showcasing 5 example Wardley maps covering different business scenarios, serving as inspiration and starting points for users.
- User Map Storage & Retrieval: Allow users to save their in-progress or completed Wardley maps to a persistent storage and retrieve them for future editing.

## Style Guidelines:

- Primary color: A deep, professional blue (#1468BA) symbolizing clarity and strategy, providing a strong anchor for the interface.
- Background color: A very light, cool grey-blue (#E9EEF3), providing a clean, spacious backdrop that enhances readability of text and map elements.
- Accent color: A vibrant aqua-cyan (#54D6D6) for interactive elements, highlights, and calls-to-action, offering a fresh, dynamic contrast to the primary blue.
- Headline font: 'Space Grotesk' (sans-serif) for titles and headings, conveying a modern and structured aesthetic suitable for a tech-oriented mapping tool.
- Body font: 'Inter' (sans-serif) for all body text and map labels, ensuring excellent readability and a neutral, professional appearance across the application.
- Utilize a consistent set of minimalist, line-based icons for all interactive elements and feature representations, maintaining a clean and intuitive user experience.
- Implement a clear, modular layout with a large, dedicated canvas area for map creation, complemented by organized sidebars for tools, properties, and concept explanations.
- Incorporate subtle and functional animations for feedback during component drag-and-drop actions, state changes, and transitions between different views or sections, ensuring a responsive feel.
